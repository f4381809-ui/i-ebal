# Карта истоков на Vercel (общий режим)

Что получится: сайт открывается по обычной ссылке, а всё, что делает администратор (места, зоны, линии,
категории, названия миров, настройки цикла, игроки и их перемещения), сохраняется на сервере и видно всем посетителям.
Пароль администратора хранится на сервере, а не в коде страницы.

## Файлы

```
index.html        сама карта
api/state.js      чтение и сохранение карты (сохранять может только админ)
api/login.js      вход администратора (проверка пароля на сервере)
lib/kv.js         общие функции: связь с базой, подпись токенов
package.json
```

## Шаги

1. **Залейте папку в GitHub.** Создайте новый репозиторий и загрузите в него все файлы из этой папки
   (кнопка «Add file → Upload files» на странице репозитория подойдёт).
2. **Создайте проект на Vercel.** На vercel.com: «Add New… → Project», выберите свой репозиторий и нажмите «Deploy».
   Framework Preset оставьте «Other», команды сборки не нужны.
3. **Подключите базу данных.** В проекте откройте вкладку **Storage**, нажмите «Create Database», выберите
   **Upstash for Redis** (бесплатный тариф подойдёт) и подключите её к проекту.
   Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
4. **Задайте пароль администратора.** «Settings → Environment Variables», добавьте:
   - `ADMIN_PASSWORD` — ваш пароль администратора;
   - `AUTH_SECRET` — любая длинная случайная строка (подпись сессий; необязательно, но лучше задать).
5. **Пересоберите проект.** «Deployments» → три точки у последнего деплоя → «Redeploy»
   (переменные окружения начинают работать только в новом деплое).
6. Откройте сайт, в боковой панели раздел «Админ» → «Войти». После изменений внизу панели будет надпись
   «Сохранено на сервере ✓». Посетители получают обновления сами примерно за 20 секунд или при перезагрузке страницы.

## Перенос того, что уже сделано в старой версии

В старой версии: «Редактор карты» → «Данные: экспорт / импорт» → «Скопировать».
На новом сайте войдите админом, откройте то же окно, вставьте текст и нажмите «Применить». Данные сразу сохранятся на сервере.

## Как это защищено

- Пароль проверяется на сервере, после входа выдаётся подписанный токен на 12 часов.
- После 10 неудачных попыток с одного адреса вход блокируется на 15 минут.
- Сохранять данные может только тот, у кого есть токен. Посетители могут только смотреть карту:
  перемещать игроков и править анкеты тоже может только администратор (в общем режиме это общее состояние игры).

## Смена пароля

Измените `ADMIN_PASSWORD` в «Settings → Environment Variables» и сделайте Redeploy. Старые токены станут недействительными,
если вы также поменяете `AUTH_SECRET`.
